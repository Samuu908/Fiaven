FiaVen es una aplicación móvil diseñada específicamente para optimizar la gestión comercial de pequeños negocios y comercios locales (como ferreterías o abastos). Su propósito principal es eliminar los tradicionales cuadernos de notas para digitalizar el control financiero diario de forma rápida y sencilla.


📱 FiaVen — Sistema de Gestión Comercial y Caja
FiaVen es una aplicación móvil multiplataforma (Android) desarrollada para simplificar el control financiero de pequeños comercios en Venezuela. Permite llevar el registro diario de transacciones y cuentas por cobrar de manera totalmente independiente y segura.

Características principales:
Control de Dinero en Caja: Registro automatizado de ventas de contado y abonos diarios, manteniendo un balance claro y real del efectivo disponible.
Módulo de Fiados (Aparte): Gestión individualizada de cuentas por cobrar por cliente, completamente separada del dinero en caja para evitar confusiones financieras.

Multimoneda y Tasa Personalizada: Soporte para operaciones en Dólares ($) y Bolívares (Bs.), con opción de sincronización con la tasa oficial del BCV o asignación de una tasa personalizada por el negocio.
Sincronización Multi-dispositivo: Conexión en la nube para mantener actualizados los datos de ventas y clientes en tiempo real entre varios teléfonos del equipo de trabajo.

Modo Offline-First: Diseñada para operar sin interrupciones incluso ante fallas de conectividad eléctrica o de internet.
